# 🤖 Kit Completo de Prompts para N8N

Este repositório contém uma coleção abrangente de prompts e guias para criar automações poderosas no N8N.

## 📚 Índice dos Arquivos

### 🎯 [Prompts Básicos](./prompts-n8n.md)
Automações essenciais para começar com N8N:
- **CRM/Vendas**: Qualificação de leads, nutrição, gestão de propostas
- **Marketing**: Social media, distribuição de conteúdo, email marketing  
- **E-commerce**: Processamento de pedidos, carrinho abandonado, reviews
- **Atendimento**: Roteamento de tickets, onboarding, feedback
- **Relatórios**: KPIs automáticos, relatórios financeiros
- **Templates**: Estruturas básicas e boas práticas

### 🚀 [Prompts Avançados](./prompts-avancados-n8n.md)
Automações complexas com IA e integrações avançadas:
- **IA**: Análise de documentos, chatbots inteligentes, análise de sentimento
- **Growth**: Lead scoring dinâmico, otimização de campanhas, prevenção de churn
- **Financeiro**: Conciliação bancária, fluxo de caixa, controle de inadimplência
- **Corporativo**: Onboarding de funcionários, compliance, aprovações
- **Segurança**: Monitoramento, backup, gestão de credenciais
- **Cloud**: Multi-cloud, arquitetura orientada a eventos, pipelines de dados
- **Setores**: E-learning, imobiliário, saúde

### 🤖 [Prompts Chatvolt.ai](./prompts-chatvolt-n8n.md)
Prompts específicos para integração com Chatvolt.ai:
- **Lead Capture**: Automação de captura de leads
- **WhatsApp Business**: Integração avançada com WhatsApp
- **Multi-Agent**: Orquestração de múltiplos agentes
- **CRM Integration**: Sincronização com HubSpot, Pipedrive
- **Analytics**: Dashboards e relatórios automáticos
- **Brazilian Market**: Funcionalidades específicas para o Brasil

### 💻 [Código Prático Chatvolt](./chatvolt-n8n-codigo.md)
Templates de código prontos para usar:
- **Webhooks**: Configurações de recebimento de dados
- **Function Nodes**: Códigos JavaScript específicos
- **HTTP Requests**: Chamadas para APIs do Chatvolt
- **Workflows Completos**: Templates prontos para implementar
- **Credenciais**: Configuração de autenticação
- **Troubleshooting**: Soluções para problemas comuns

### 📖 [Guia de Implementação](./guia-implementacao-n8n.md)
Manual completo de como implementar os prompts:
- **Setup**: Preparação do ambiente e configurações
- **Fluxo**: Passo a passo para implementação
- **Templates**: Códigos prontos para nós essenciais
- **Padrões**: Arquiteturas comuns de workflows
- **Debug**: Como identificar e resolver problemas
- **Performance**: Otimizações e boas práticas
- **Segurança**: Proteção e governança
- **Go-Live**: Checklist para produção
